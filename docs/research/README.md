# Research Registry

Research artifacts preserve external evidence and option analysis. They inform decisions but do not become policy until an approved specification, plan, ADR, architecture document, or runbook adopts the conclusion.

## Required metadata

Each research document must record:

- question and scope;
- date and researcher;
- authoritative sources with direct URLs and access dates;
- relevant source facts, paraphrased accurately;
- project-specific synthesis clearly labeled as synthesis;
- risks, unknowns, and follow-up questions;
- links to decisions or SDD artifacts that consume the research.

Prefer primary sources: vendor documentation, specifications, standards, maintainers' repositories, and original publications. Verify current APIs, security requirements, and dependency behavior live when they can drift.
